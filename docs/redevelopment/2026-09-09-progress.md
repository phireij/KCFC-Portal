# KCFC Portal Redevelopment Progress — 2026-09-09

## Branch

`redesign/mobile-first-v2`

Draft PR: #1 — **Redevelopment: mobile-first shell and schedule foundation**

Production `main` remains unchanged.

## Completed in the active redevelopment branch

### 1. Responsive application shell

- New official KCFC navy / royal-blue visual foundation.
- Mobile navigation is now exactly five primary destinations: Home, Schedule, Community, Updates, More.
- Horizontal scrolling navigation has been removed from the new shell.
- Desktop uses a persistent left sidebar with role-aware utility and leadership links.
- Mobile More opens as a bottom sheet and contains Availability & Polls, Resources, Inbox, Profile, Accounting when authorized, and Leadership/Admin when authorized.
- Reading-size defaults were normalized toward the approved 15–17 px body range while preserving user-selectable larger accessibility sizes.

### 2. Schedule experience

- Existing detailed duties/assignment page was preserved as `LegacyDuties.tsx` for regression safety.
- `/duties` is now a member-oriented Schedule hub.
- **All schedule** shows chronological Mass dates and expandable published ministry rosters.
- **My ministry** shows the member's own upcoming liturgical assignments and community duties in one timeline.
- **Plan & manage / Availability & duties** keeps the existing assignment workspace available while it is progressively rebuilt.
- Legacy notification/deep links containing `tab` or `pollId` automatically open the detailed workspace.
- Draft/unfinalized roster names are not exposed in the new member schedule.

### 3. Home experience

- Existing dashboard was preserved as `LegacyDashboard.tsx` for reference/regression safety.
- Home is now member-first rather than admin-statistics-first.
- Home highlights:
  - next published assignment,
  - next KCFC Mass,
  - availability-response status,
  - action-needed availability alert,
  - leadership membership-approval alert when applicable,
  - next Mass dates,
  - latest announcements,
  - quick links to Community, Inbox, Resources and Availability.
- No destructive database actions are present in the new member Home surface.

## Data handling

The new Home and Schedule surfaces are read-only consumers of the existing Firestore collections. They do not migrate, delete, recreate or rewrite member records.

Current compatibility sources:

- `users`
- `polls`
- `polls/{pollId}/responses`
- `duties`
- `announcements`
